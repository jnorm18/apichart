TOTAL - - - - - -
Defaults follow the uploaded table spec: total 2030 capacity is estimated from the average year-on-year change in total generation over the latest up to 3 historical intervals, extended linearly to 2030, then distributed across technologies using latest capacity shares. In total-target mode, the 2030 total is also split across technologies using those latest capacity shares. Capacity factors default to each technology's latest observable implied value using the latest common year where both historical generation and capacity exist, and editable capacity factors are capped between 0 and 1.

Repo setup for the capacity chart: add a file at data/capacity_yearly.csv. The important columns are Area, Year, Category, Subcategory, Variable, Unit, and Value. This page keeps only Category = Capacity, Subcategory = Fuel, and Unit = GW.
