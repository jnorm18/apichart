V2.5 beta • Historical data plus projections and derived charts

Electricity generation and capacity explorer

Generation is pulled from Ember's API. Capacity is pulled from a local yearly file in your repo. This version adds an editable 2030 projection panel, extends both main charts beyond the latest historical year, and adds derived charts for capacity factors and annual capacity additions / retirements. The projected section is shown with lighter fills and a shaded projection band. Capacity starts projecting from its first unavailable year, and generation starts projecting from its own first unavailable year.

Edit the 2030 capacity and capacity factor assumptions row by row. Capacity factors are derived from the latest common historical year with both capacity and generation data, capped between 0 and 1, and can be edited directly. Capacity is linearly interpolated to 2030, and generation is then calculated from projected capacity and projected capacity factors while staying visually continuous with the latest historical generation year.

Repo setup for the capacity chart: add a file at data/capacity_yearly.csv. The important columns are Area, Year, Category, Subcategory, Variable, Unit, and Value. This page keeps only Category = Capacity, Subcategory = Fuel, and Unit = GW.
