V1 • Ember API annual generation

Electricity generation explorer

Select a country and draw a stacked annual generation chart using Ember's yearly electricity-generation endpoint. Your API key is stored locally in your browser so you do not need to commit it to GitHub.

Saved in your browser only. It is not written into the repository.
The dropdown is populated from Ember's options endpoint.
Default matches Ember's yearly endpoint.
Enter your API key, then load the country list.

Data source: Ember API. Ember states that its data is published under CC-BY-4.0 and asks that Ember is cited as the source. If the browser blocks direct API calls from GitHub Pages because of CORS, the next step would be to add a lightweight proxy.
