Electricity generation and capacity explorer

Generation is pulled from Ember's API. Capacity is pulled from a local file in your repo and now filters specifically to yearly capacity rows only. Both charts update automatically when you change the country or start year.

Repo setup for the capacity chart: add a file at data/capacity_yearly.csv. For a full Ember-style yearly file, the important columns are Area, Year, Category, Subcategory, Variable, Unit, and Value. The capacity chart now keeps only Category = Capacity, Subcategory = Fuel, and Unit = GW.
